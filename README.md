# CF MEMO — Fitness Notes

クロスフィット・食事・休養に特化したメモWebアプリ。スマホでの利用を前提にしたモバイルファーストのダークUIです。

## 機能

- **今日** — 12週間トレーニングプランの「その日やること」を1画面で表示。AM(CrossFit) / PM(Bodymake・Run・Rest) / 食事パターンをカードで並べ、PMは種目・セット×回数・強度・中止条件まで展開できます。前後の日送り・週カレンダーでの日付切り替え、その日の内容を流し込んだメモの下書き作成、プラン全体 (週ごとの進行・食事パターン・ルール・12週レビュー) の閲覧に対応
- **トレーニング解説** — 各日の「狙い」と、開いて読む詳しい解説 (バーピーの技術チェック7項目、木曜の隔週構成と400mの判定基準、ペース配分、夜トレの中止判断、食事の考え方など)。英語の種目名・用語には日本語訳が付きます
- **メモ** — カテゴリ (WOD / 食事 / 休養 / その他)・タグ・複数画像添付に対応
- **検索** — タイトル・本文・タグを対象としたキーワード検索 + カテゴリ絞り込み
- **PR記録** — 種目ごと (Push Press など) にベスト記録・過去履歴・重量の推移グラフを表示。記録入力時にはその種目の過去記録も確認できます
- **WODスキャン** — ホワイトボードのWOD画像を撮影すると自動で読み取り。種目名 (英語+日本語)・回数・重量・Time Capまで構造化して取り出し、保存した日付の「今日」タブのAM欄にそのまま反映されます。結果は保存前に編集でき、自分の記録も添えてメモとして保存されます
- **オフライン動作** — データはすべてブラウザの IndexedDB に保存。OCRのモデル・ワーカーもアプリに同梱しているため、電波の悪いジムでも動作します

## 技術構成

- [Vite](https://vitejs.dev/) + React 18 + TypeScript
- [Tesseract.js](https://tesseract.projectnaptha.com/) によるクライアントサイドOCR (CDN非依存・同梱)
- IndexedDB (メモ・PR記録・画像Blob)
- 依存を最小限にしたプレーンCSS (モバイルファースト)

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド (dist/)
npm run preview  # ビルド結果の確認
```

`npm run build` の成果物 (`dist/`) は相対パス構成 (`base: './'`) なので、GitHub Pages などの静的ホスティングにそのまま配置できます。

### WOD読み取りについて

読み取りは2通りあり、スキャン画面の「読み取りの設定」で切り替わります。

| | 使うもの | 手書きの精度 | 通信 |
|---|---|---|---|
| 高精度 (既定) | Claude の画像入力 (`claude-opus-5`) | 手書き・かすれ・斜めでも読める | Anthropic APIへ画像を送信 |
| オフライン | Tesseract.js (端末内OCR) | 活字向け。手書きはほとんど読めない | なし |

高精度の読み取りには Anthropic の APIキーが必要です。**キーは利用者が自分で入力し、その端末のブラウザ内 (IndexedDB) にのみ保存されます。** リポジトリにもビルド成果物にも含まれず、Anthropic 以外のどこにも送信されません。キー未設定の場合はオフラインの端末内OCRだけが使えます。

画像は送信前に長辺2576pxまで縮小します (Claudeの高解像度入力の上限。それ以上送っても精度は上がらず画像トークンだけ増えるため)。

### OCRアセットについて

- `public/tessdata/` — 言語データ ([tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) の eng / jpn、リポジトリに同梱)
- `public/tesseract/` — ワーカーとWASMコア。`npm run dev` / `npm run build` 時に `scripts/copy-tesseract.mjs` が node_modules から自動コピーします (gitには含まれません)

## トレーニングプランのデータ

「今日」タブが表示するプランは `src/plan/planData.ts` の静的データです。元データは
`CrossFit_BodyMake_12week_Plan_20260813.xlsx` (2026/08/13〜2026/11/04 の12週間プラン) で、
日次ログ・月次カレンダー・トレ詳細・食事パターン・12週レビューの各シートから生成しています。

プランを変更するときはスプレッドシート側を更新し、`src/plan/planData.ts` を差し替えてください。
表示ロジック (日付計算・セッション種別の色分けなど) は `src/plan/plan.ts` にあります。

解説・技術ポイント・用語集は `src/plan/guideData.ts` にまとめています。こちらはスプレッドシート
由来ではなく手で書いた内容なので、planData.ts を再生成しても影響を受けません。

## データについて

メモ・PR記録・画像・WODスキャン結果・APIキーは、すべて端末のブラウザ内 (IndexedDB) にのみ保存されます。ブラウザのサイトデータを消去すると記録も消えるためご注意ください。

外部に出るのは、高精度のWOD読み取りを実行したときにホワイトボードの画像を Anthropic API へ送信する場合だけです。オフラインの端末内OCRを使う場合、または読み取りを行わない場合は、何も送信されません。

# きょうトレ (KYOTORE) — 今日のワークアウト自動作成サイト

`/workout/` で公開する、誰でも使えるワークアウト生成サイトです (CF MEMO とは別ページ・別データ)。
7つの質問 (施設型ジム / CrossFit・なりたい姿・鍛えたい部位・使える時間・レベル・体調・痛み、CrossFit のみ重量基準) に答えると、
**ウォームアップ (4分) とクールダウンのストレッチ (2分) の計6分を含めて**、選んだ時間に収まるその日のメニューを作ります。

## 機能

- **診断 → メニュー生成** — 1画面1問・タップだけで約30秒。生成はすべて端末内 (APIキー・通信不要)
- **トレーナーの解説** — なぜこの種目・回数・休憩なのか、注意点、次回の進め方 (ダブルプログレッション) を毎回表示
- **施設型ジム** — 部位ごとの「枠」(例: 背中 = 縦に引く → 横に引く → ヒンジ → 単関節) を優先順に埋め、目的別にセット・回数・休憩・RIR を設定。時間が足りなければ競合しない部位同士をスーパーセットに。1部位のセット数に上限を設け、余った時間は低強度の有酸素へ
- **CrossFit** — ストレングス → WOD → 補強のクラス形式。WOD は AMRAP / For Time / 21-15-9 / チッパー / EMOM / インターバル / タバタから目的と時間で選び、1回あたりの秒数から回数・目標ラウンド数・タイムキャップを逆算。各種目に Rx / Scaled / 初心者 と★のおすすめ
- **体調・痛み・履歴で調整** — 疲れ気味なら量と強度を下げる、腰・ひざ・肩・手首に負担の大きい種目を外す、前回の「きつさ」でボリュームを増減、最近やった種目を避ける、「おまかせ」なら回復している部位を優先
- **実行サポート** — セットのチェック、休憩タイマー、AMRAP / EMOM / For Time / インターバルのタイマー (カウントダウン音・画面スリープ防止)、ガイド付きウォームアップ、種目の入れ替え、フォーム動画検索、1RM からの重量計算
- **記録と継続** — 完了時に「きつさ」とスコアを記録。週の目標・連続達成週・直近7日の部位バランス・カレンダー
- **シェア (集客導線)** — メニューのURLを LINE / X で送ると相手の端末で同じメニューが開く (履歴の要約もURLに含めて完全再現)。完了記録は SNS 用の画像 (1080×1350) にして共有。共有リンクから来た人には「自分用に作る」を案内
- **SEO / SNS** — メタディスクリプション、OGP 画像 (`public/workout/og.png`)、構造化データ (WebApplication)、ホーム画面に追加できる manifest。CF MEMO 側は引き続き noindex

## 構成

| パス | 内容 |
|---|---|
| `workout/index.html` | エントリ (SEO・OGP タグ) |
| `src/workout/engine/` | メニュー生成エンジン (UI 非依存)。`exercises.ts` 施設型ジムの種目、`crossfit.ts` WOD 種目・リフト、`gym.ts` / `box.ts` 生成ロジック、`warmup.ts` ウォームアップとストレッチ、`index.ts` 入口と共有コード |
| `src/workout/components/` | 画面 (LP・診断・結果・タイマー・完了・記録) |
| `src/workout/storage.ts` | 端末内 (localStorage) の保存 |
| `src/workout/track.ts` | 計測フック。GA4 などのタグを `workout/index.html` に入れると `generate_workout` / `complete_workout` / `share` などのイベントが送られる |
| `scripts/check-workouts.mjs` | 回答の全組み合わせ (15,552通り) でエンジンを検証 |

ウォームアップ・ストレッチの時間は `src/workout/engine/common.ts` の `WARMUP_SEC` / `COOLDOWN_SEC` で変えられます。

```bash
npm run dev            # http://localhost:5173/workout/
npm run check:workout  # 時間超過・空ブロック・共有URLの再現性などを検証
```

種目を追加するときは `exercises.ts` / `crossfit.ts` に足して `npm run check:workout` を通してください。共有URLの種目IDはハッシュで短縮しているので、並び順を変えても古いURLは壊れません (ID 自体は変えないこと)。

OGP の URL は `https://onemuscle.github.io/CF-Memo/workout/` を前提にしています。独自ドメインで公開する場合は `workout/index.html` の canonical / og:url / og:image を書き換えてください。
