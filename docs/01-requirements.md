# 1. 要件の整理

## 目的

日々の記録 (トレーニング・持久力・食事・体組成・睡眠・コンディション) を一生ぶん安全に蓄積し、
Claude Code が専属コーチ・栄養アドバイザー・パフォーマンスアナリストとして分析・予測・提案できる個人用プラットフォーム。

役割分担:

| 担当 | やること |
|---|---|
| Web アプリ (スマホ・PC) | 素早い記録、グラフ・ダッシュボード、決まった計算 (推定1RM・トレンド・負荷比・達成予測) |
| データベース (Cloudflare D1) | すべての記録の正本。コードと完全に分離 |
| Claude Code | 自然文の報告を記録に変換、WOD 分析、週次・月次レポート、方針の提案、開発・保守 |

## 最重要要件: データの永続性

| 要件 | 対応 (詳細は 03-data-safety.md) |
|---|---|
| コードとデータの分離 | データはクラウド DB (D1)。Web アプリ・API は何度作り直してもデータに触れない |
| 修正・再デプロイでデータが消えない | デプロイは「マイグレーション (列の追加のみ) → コード差し替え」。DB を作り直す処理はどこにも無い |
| クラウド DB | Cloudflare D1 (SQLite 互換) |
| バックアップ・復元 | ①D1 の巻き戻し (Time Travel) ②毎日の暗号化 SQL バックアップ (GitHub Actions) ③デプロイ直前のバックアップ ④手動の JSON 書き出し ⑤ゴミ箱 ⑥変更履歴からの取り消し |
| スキーマ変更時の安全な移行 | 追加専用マイグレーション、確定済みマイグレーションの改ざん検出、DROP/RENAME/DELETE を CI で禁止、既存データ入りでの移行テスト |
| PC・スマホから同じデータ | Web アプリ (PWA 対応)。データはサーバー側 |
| 本人認証・アクセス制御 | Cloudflare Access (メールのワンタイムコード) + Worker 側での署名検証 + 機械用 API トークン。どちらも無ければ拒否 |

## 機能要件

### ① CrossFit・筋力
- WOD・種目・重量・回数・タイムの記録 → `workouts` / `strength_sets` ✅
- 1RM 管理 (実測・推定1RM・回数別ベスト) ✅
- スキル習得 (到達度・最大連続回数) → `skill_logs` ✅
- 自己ベストと更新履歴 ✅ / 種目別の成長グラフ ✅
- 目標達成までの予測 ✅ (トレンド + 頭打ち補正 + 上限 + 幅)
- 弱点分析 ✅ (種目間比率) / プログラム提案 → Claude Code (データを読んで提案)

### ② 心肺・持久力
- ラン・バイク・Zone2 の記録 (心拍・ペース・ケイデンス) ✅
- HYROX・マラソンの大会記録 (予定・結果・スプリット) ✅
- 有酸素効率の推移・週間距離・Zone2 時間 ✅
- 大会に向けた練習計画 → Claude Code / タイム予測 ✅ (Riegel 式・注意書き付き)

### ③ 食事・栄養
- カロリー・PFC・食事内容・時刻 ✅ (1食ずつ / 1日合計のどちらでも)
- 体重・体脂肪率・筋肉量・腹囲の推移 ✅
- 減量・増量に応じた目標の調整 ✅ (12週プランの調整ルールで提案)
- サプリメント ✅ / トレーニングと栄養の関係 → 相関 (データ14日以上) + Claude Code

### ④ 睡眠・コンディショニング
- 睡眠時間・質・HRV・安静時心拍 ✅ / 疲労・筋肉痛・ストレス ✅
- 怪我・不調の履歴 (避ける動き付き) ✅
- 負荷と回復 (負荷比・単調性)、オーバートレーニングの参考指標、回復優先の提案 ✅

### ⑤ AI 分析・将来予測
- 週次・月次・年間の集計 ✅ / 文章のレポート → Claude Code が作成して DB に保存 ✅
- 3か月・6か月・1年後のシミュレーション ✅ (推定1RM。体重は4〜12週)
- 関係性 (睡眠・負荷・栄養 ↔ コンディション) ✅ (相関・n 表示・14日未満は参考外)
- データ不足時は不確実性を明示 ✅

### Claude Code 連携・継続性
- 自然文の報告 → DB 登録 (CLI `cfm`) ✅
- セッションが変わっても復元: CLAUDE.md (ルール) + DB の profile/goals/journal (中身) + docs/ (設計・経緯) ✅
- Apple Watch 連携 → iPhone ショートカット経由の API (docs/apple-health.md) 🟡 手順のみ

### デザイン
- ダーク基調・グラフ・自己ベスト・達成率・スマホ最適化・素早い入力 ✅
- 拡張性: 記録項目は `shared/schema.ts` の定義から画面・API・CLI が自動で組み上がる ✅

## 非機能要件

- 無料枠中心で長期運用 (02-architecture.md)
- 電波の悪いジムでも記録が消えない (送信待ちに保存して再送) ✅
- 個人データを公開リポジトリに出さない (検査スクリプト + CI) ✅
- 検索エンジンに出さない (noindex・robots.txt) ✅
