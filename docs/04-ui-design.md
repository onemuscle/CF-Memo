# 4. 画面構成とデザイン

## デザインの方針

- **ダーク基調** (#0a0b0e)。アクセントは旧 CF MEMO と同じライム (#c6ff3e) で、ブランドを引き継ぐ
- 数字は Oswald (縦長の数字書体)、本文は Inter + Noto Sans JP。数字が主役のダッシュボード
- グラフの色は暗い背景で見分けやすく、色覚の違いでも区別しやすい並びに固定 (青 → 橙 → 緑 → 黄)。2系列以上は必ず凡例
- 状態色 (良い・注意・危険) は系列色と分け、必ず文字ラベルを添える (色だけで伝えない)
- スマホ最優先: タップ領域 44px 以上、入力欄は16px (iPhone のズーム防止)、下部タブ、入力は下から出るシート
- 推定値には必ず「推定」「幅」「根拠の件数」を表示。データ不足は数字を出さずに理由を出す

## 画面構成 (下部タブ5つ)

| タブ | 内容 |
|---|---|
| **ホーム** | 今日のコンディション (目安スコア・理由・注意)、8つのクイック入力 (WOD/重量/有酸素/体重/食事/睡眠/体調/スキル)、今週の集計、トレーニング負荷 (負荷比)、今日の栄養と目標、目標の達成率と到達予想日、最近の自己ベスト、体重90日グラフ、次の大会 |
| **記録** | すべての種類の追加ボタン、日付ごとのタイムライン (種類で絞り込み)。タップで編集・削除 |
| **分析** | 筋力 (種目別の推定1RM推移・回数別ベスト・3/6/12か月予測・種目間バランス・スキル) / 持久力 (週間距離・Zone2時間・ペース・有酸素効率・タイム予測・大会) / 体・栄養 (体重と7日平均・4〜12週予測・体脂肪率・筋肉量・腹囲・カロリーとたんぱく質の14日・摂取目標の見直し提案・サプリ) / 回復 (睡眠・日別負荷・HRV・安静時心拍・相関・怪我の履歴) / レポート (週・月・年の集計、Claude Code のレポート) |

## 入力をすばやくする工夫

- 日付は今日が初期値。主要項目だけ表示し、残りは「詳細項目」に畳む
- 1〜5 の評価・選択肢はボタン (チップ) で1タップ
- 種目名・スキル名は過去の記録とよく使う種目から候補表示 (表記ゆれは自動でまとめる)
- 時間は `25:30` や `1:05:00`、睡眠は `6:30` や `6.5` のように自然な書き方で入力できる
- 睡眠・コンディションは同じ日に何度入れても1件にまとまる (追記)
- 通信できなくても端末に保存し、つながったら自動送信 (送信待ちバナーで件数表示)

## 拡張性

画面のフォームと一覧は `shared/schema.ts` の定義から自動で作られる。項目を1つ足すと、入力画面・一覧表示・API の検証・CLI に同時に反映される。
新しい分析は `shared/analytics.ts` に関数を足し、テスト (`tests/analytics.test.ts`) を書いてから画面に出す。
