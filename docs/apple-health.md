# Apple Watch / ヘルスケア連携

Apple のヘルスケアデータには Web から直接アクセスする仕組み (公開 API) がありません。
そこで **iPhone の「ショートカット」アプリ** が毎朝ヘルスケアから値を読み、このプラットフォームの API に送る方式にします (無料・追加アプリ不要)。

| 送る値 | 送り先 | 1日1件 |
|---|---|---|
| 睡眠時間・HRV・安静時心拍 | `/api/e/sleep_logs` | ✔ (同じ日は追記) |
| 歩数・アクティブカロリー・エクササイズ時間・VO2max・安静時心拍・HRV | `/api/e/daily_health` | ✔ |

どちらも `source` を `health` にして送るので、手入力 (`web`) の記録とは別の行になり、上書きし合いません。

## 作り方 (約15分)

> Phase 2 で一緒に動作確認しながら仕上げる予定です。うまくいかなければ Claude Code に画面のスクリーンショットを見せてください。

1. ショートカットアプリ → **+** → 名前「CF MEMO 送信」
2. **日付** → **日付をフォーマット** (カスタム `yyyy-MM-dd`) → 変数「今日」
3. **ヘルスケアのサンプルを検索**: 種類 **睡眠分析**、開始日が **過去1日**、値が **睡眠中 (コア・深い・レム)**
   → **ヘルスケアのサンプルの詳細を取得: 継続時間** → **統計を計算: 合計** → 分に換算 → 変数「睡眠分」
4. 同様に **安静時心拍数** (過去1日・最新1件)・**心拍変動** (過去1日・平均)・**歩数** (今日・合計)・**アクティブエネルギー** (今日・合計)
5. **URL の内容を取得**
   - URL: `https://cfm.<名前>.workers.dev/api/e/sleep_logs`
   - 方法: POST
   - ヘッダ: `Authorization` = `Bearer <API_TOKEN>`、`Content-Type` = `application/json`
   - 本文 (JSON): `date` = 今日、`duration_min` = 睡眠分、`hrv_ms` = HRV、`resting_hr` = 安静時心拍、`source` = `health`
6. もう1つ **URL の内容を取得** で `/api/e/daily_health` に `date`・`steps`・`active_kcal`・`resting_hr`・`hrv_ms`・`source` = `health`
7. **オートメーション** タブ → **個人用オートメーション** → **アラームが停止されたとき** (または「睡眠」集中モードがオフになったとき) → このショートカットを実行・**すぐに実行**

注意:
- `API_TOKEN` はショートカットの中 (あなたの iPhone 内) に保存されます。ショートカットを他人に共有しないでください
- iPhone がロック中はヘルスケアを読めないため、起床後 (ロック解除後) に動くトリガーにしています
- 値が取れなかった項目は空のまま送られ、サーバー側で無視されます

## 有料アプリを使う場合

「Health Auto Export」などのアプリは、ワークアウト (心拍・ペース・距離) も含めて自動送信できます (年額課金)。
送信形式が独自なので、使う場合は受け口 (形式の変換) を Phase 2 で追加します。
